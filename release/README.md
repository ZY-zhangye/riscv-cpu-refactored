# Competition Release Archive

`CICC1005400.zip` is the archived competition-time FPGA implementation package
used for the final synthesis/bitstream submission. It is intentionally stored
as a single archive: the repository does **not** include an expanded Vivado
project or generated build directories.

Archive size: 90,367,933 bytes.

SHA-256:
`c1b2fdc9dfdf43957b617d22257ce6d41ed49a66f92c4aee61d8263e3e877ae2`

The archive contains the competition synthesis outputs and its accompanying
project snapshot. Keep it unchanged when reproducing the submitted result.

## Competition test program

`tests/3_cpop.zip` is the supplied competition test-program package from the
desktop file `3、cpop.zip`. It contains `withMext_cpop` and
`withoutMext_cpop` IROM/DRAM initialization images plus reference outputs for
the `cpop` test. Like the implementation archive, it is stored without
expansion so the submitted test inputs remain byte-for-byte traceable.
